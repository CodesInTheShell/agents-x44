# agents-x44
A collection of agents md for agentic ai tools.

## Usage

Clone this repo, then copy the agent folder you need, or just the individual agent files you want, into your own agent directory.

Typical usage:

- For Codex-style agents, copy files from `codex/agents/` into your global or repo-specific `codex/agents/` directory.
- For Claude-style agents, copy files from `claude/agents/` into your global or repo-specific `claude/agents/` directory.

You can either:

- Copy the whole folder if you want all provided agents.
- Copy only specific agent files if you want a smaller custom set.
